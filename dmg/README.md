# TokenMeter 本机安装包

每个版本的 DMG 放在 `dmg/<release_id>/`，可直接从仓库根目录打开。本目录中的 `.dmg` 文件只保存在本机，不随 Git 上传；Git 保存本说明和版本文档。

文件名中的状态决定用途：

| 文件名标记 | 含义 |
| --- | --- |
| `DEVELOPMENT-NOT-RELEASED` | 开发包，供本机诊断；尚未通过发布门禁 |
| `CANDIDATE-NOT-RELEASED` | 待验收候选包；尚未通过发布门禁 |
| `internal.dmg` | 门禁 PASS 后，从同一已验证原包复制并核对摘要的内部安装包 |

当前版本 `v0.1.0-20260929T074814Z` 只有开发包。实际产品 E2E 中升级场景 004 失败，正式安装包尚未生成。原始构建包、测试日志与清单保留在 `.local/`，本目录中的开发包是相同字节的便捷副本。
