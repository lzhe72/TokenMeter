# SOP-009 环境准备

**修订：** 1　**状态：** baselined　**适用：** all

## 目的与范围

准备可隔离、可复现的开发和自动测试环境，明确本机能力与真正产品运行条件。

## 触发条件

首次开发/测试、工具链变化、新建 Mac runner，或运行因环境缺失中断。

## 前置条件

SOP-008 文档基线完整；测试计划列出需要的 macOS、架构、Xcode、GUI、数据库和权限。

## 输入

候选版本、依赖配置、平台矩阵、测试目录/数据库约定、CI/签名权限需求。

## 执行步骤

1. 先只读检查系统/架构与工具链；先运行 xcode-select -p；只有已选择完整 Xcode 时再运行 xcodebuild -version。未配置时直接记录缺项，避免触发系统安装提示；区分仅有 Command Line Tools。
2. 检查已登录的桌面会话、原生测试目标、UI 自动化授权和受支持系统；不把交叉编译当作该平台执行。
3. 按已提交依赖配置准备运行时；为本次运行划定专用目录、数据库、测试 Keychain 项和服务端口。
4. 核对目标为测试环境、具有所有权标记；只检查本任务所需权限，不打印凭据或静默改变开发者系统配置。
5. 产品 App/服务、数据库初始化、runner、签名或发布访问尚缺时逐项记录 BLOCKED 和恢复条件；可继续独立的规范/工具自测。

## 输出

环境清单、隔离目标、依赖/权限检查结果、恢复条件及清理责任。

## 成功与失败判据

所需真实运行环境全部可用才可执行相应产品步骤；当前仓库缺 App/服务和原生 E2E，完整产品执行保持 BLOCKED。基础 Python 可用不等于 Mac 产品环境就绪。

## 异常恢复

环境错误先保留检测结果，修复明确缺项后重检；不删除真实日志/账号或以绕过系统权限替代授权路径。

## 证据位置

版本记录保存系统/架构/工具链与具体缺项；机器运行报告记录环境标识、版本和隔离资源路径。
