# 产品约定

状态：已确认的首版范围；TM-001正在开发验收，其余功能按路线图推进。实现与测试状态以 [功能矩阵](../../tests/feature_matrix.json) 和执行证据为准。

## 用户与采集范围

- 一个部署服务一个团队。v0.1.0 首次初始化生产 SQLite 时预置 `admin / 123456` 并强制首次改密；测试库只供 Codex 隔离回归。无开放注册；成员只能查看自己的数据，管理员可查看团队。
- 首版只读本机 Codex、Claude Code 已有日志，含可核实的子代理用量。用户授权目录后导入并增量读取，不修改工具配置、不代理请求。
- 统计日志中可识别的模型，如 GPT、Sonnet、Opus、Qwen、GLM；未知模型保留原始标识。支持模型不能等同于支持所有调用该模型的应用。
- 不采集对话或代码正文。界面显示已发现时间范围、缺失字段、未知格式、最后采集/同步时间。

## 固定口径与默认值

- 存储时间 UTC；团队默认 Asia/Shanghai。近 N 天包含今天，按自然日分组。
- 首次导入默认最近 30 天，可调整；不存在的历史不能补零。
- 输入/输出、缓存读取/写入、推理 Token 按来源语义标准化，子项不能重复加入总数。
- 日志包含请求标识时才统计请求数；日志行数不是请求数。
- 估算费用保留价格版本，不把订阅折算值称为实际账单；首版不自动换汇。
- 文件变更触发读取，每 30 秒补扫；每 60 秒同步，支持手动刷新。App 退出后停止采集，下次补扫。
- 本地用量默认保留 90 天，服务器 365 天，可配置；按团队时区的自然日计算并包含今天，仅清理早于保留首日 00:00 的事件。客户端未确认上传的数据不受常规过期清理影响。
- 未分配项目归入“未归属”；项目映射由用户明确设置。
- 首个内部版本支持 macOS 15，Apple Silicon 和 Intel；这是用户2026-09-30按现有测试条件确认的范围。macOS14和其他系统主版本待后续扩展验证；发布支持矩阵必须用最终包真实 runner 证据证明。
- v0.1.0 登录页“在此设备上自动登录”默认开启：开启时仅将服务端随机、可撤销、固定30天到期且不滑动续期的 token 存于当前用户受保护文件；取消勾选后，在本次成功登录接收会话时删除当前服务旧凭据，新会话只驻内存，重启回登录。启动恢复必须联网经 `/v1/me` 验证；离线、过期、改密、重置、停用后不得显示已登录。退出本地立即清理，断网时明确服务器撤销尚待确认。生产凭据位于 `~/Library/Application Support/TokenMeter/credentials`，目录0700、文件0600、当前uid、拒绝symlink、按规范化API origin（scheme/host小写、去默认80/443端口与尾斜线）隔离并原子写；不保存密码。此处“本设备”指本机文件保存范围，不作硬件绑定，同uid进程可读取，复制出的token可能在别处使用。旧预览版不迁移Keychain，首次需重新登录一次。
- v0.1.0 正式 App 首次启动默认使用 `http://127.0.0.1:49176`，登录页允许修改 TokenMeter 服务地址。明文 HTTP 只限本机回环；其他主机必须使用 HTTPS。`127.0.0.1` 指当前运行 App 的这台 Mac，其他设备若连接团队服务器需要在登录页配置其 HTTPS 地址。
- v0.1.0 更新源默认 `http://127.0.0.1:49177/appcast.xml`，指运行 App 的同一台 Mac，与 API 的 49176 端口分开。管理页可修改并保存更新源地址，也可恢复本版内置默认；显式覆盖跨启动和升级保留。更新源允许 appcast 路径，但拒绝 userinfo、查询、fragment、空主机与非法端口。HTTP 只允许精确回环主机 `127.0.0.1`、`localhost`、`::1`，非回环必须 HTTPS；下载地址与重定向也须遵守边界。用户改变地址不会改变 App 固化的 EdDSA 公钥。

## 成功标准

同一组确定性数据重复扫描、重启、断网补传后，个人与团队结果仍与独立预期一致；成员不能查看他人数据；每项已交付功能的自动 E2E 在同一候选提交上通过。缺少任何证据时不能发布。

## 分阶段交付边界

- 0.1.0 验收真实 App→认证接口→账号数据库→界面的登录、设备自动登录和账号管理链路，成员本人身份与管理员操作权限必须由服务端校验。统计越权和停用账号上传在 0.7.0 的同步/统计链路中验收。
- 0.1.0 验收首次启动的本机默认地址、登录页切换隔离服务、重启后保持手动配置、不同服务的会话隔离，以及非回环 HTTP 的拒绝。生产服务器地址尚未确定；未来配置生产服务器的版本将内置其 HTTPS 默认地址，并通过真实升级验证：从未手动改过地址的安装采用新版默认值，已经手动设置的地址保持不变。该迁移归入 TM-010 的计划验收，若生产服务器更早就绪则在对应版本立项时前移。
- 0.2.0 验收目录选择、候选文件预览、授权保存与恢复，记录采集/同步意愿；按日志内容识别时间/用量以及重新授权后的去重在 0.3/0.4.0 验收。0.3/0.4.0 同时提供必要的采集状态及用量核对界面；0.5.0 再交付完整日期筛选、趋势和明细。
- 0.1.0 包含最小签名更新器作为持续交付基础：本机回环默认更新源、配置管理页、点击升级、EdDSA 签名校验、失败保持原版；非回环更新源使用 HTTPS。首次无历史稳定版时，验证候选干净安装，再由该候选升级至受控高版本签名测试包，开启自动登录时升级重启须经 `/v1/me` 无交互恢复；测试包仅用于隔离验证，不作为公开发布。自 0.2.0 起，每次发布均从上一公开稳定版验证自动更新。0.10.0 完善更新设置、版本说明与异常体验，不能把早期版本交付为没有更新器的安装包。
- 数据库初始化与随版本 schema 变化所需的兼容/恢复检查从首项功能开始；0.11.0 交付面向用户的完整备份、恢复与数据库迁移能力。版本依赖详见[路线图](../roadmap.md)。
