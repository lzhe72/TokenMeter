> 2026-09-30当前执行基线：[Electron本机设计](architecture/01-electron-local.md)。Electron/React/TypeScript、Vite/electron-vite、Playwright Electron、electron-builder；本机开发/全量测试/打包，当前仅macOS15 Intel实测范围。Git保存源码/文档/版本；DMG、更新包、报告和通行证只存本地，Actions仅明确多环境要求时启用。旧流程在历史提交与明确标记的历史设计中查询。每项功能真实E2E与发布门禁不变。

## 最高约束

1. 规范驱动文档，文档驱动设计、开发、测试、发布和产品迭代。
2. 每一步必须有 SOP；根 sop/README.md 为总索引，每项工作一份独立文件，按步骤拆分。AGENTS.md 强制第一步查索引，再完整读对应 SOP、验证输入输出并保存证据；缺失或冲突先按 SOP-000 修订。
3. 先建立需求→功能拆解→开发计划→测试计划→发布预案的框架和文档，再按文档开发、验证、发布，之后进行下一轮迭代。
4. 项目由大模型开发，需要 AGENTS.md、docs、状态和交接记录，便于 Codex 理解、修复和继续迭代。
5. 每项功能都有测试用例及测试数据；所有测试账号和数据同时具备程序与 SOP。Codex 自动编写、执行、判断门禁；每次迭代和发布均须 E2E 通过才可上线。
6. Changelog 标题为版本；Git 发布编号包含版本号和时间。一个编号可查询需求、功能拆解、开发/测试计划、用例、发布文档、通行证及 Git 发布。

## 产品范围决定

- macOS 桌面 App TokenMeter；首版只读 Codex 和 Claude Code 已有本地日志，记录日志中可识别的 GPT、Sonnet、Opus、Qwen、GLM 等模型。
- 首次启动引导权限授权；不改用户 API 地址、不引入代理。其他 App/独立 API 来源后续适配。
- 团队集中管理，一套服务一个团队；预置账号，无开放注册。
- 今天、昨天、近 7/15/30 天可配置；Token 与费用估算。
- 本地数据库文件；v0.1.0 服务端先使用 SQLite，MySQL 留到后续迁移版本；自动发现版本，用户点击更新。
- 一项功能一个版本，小功能升次版本，重大功能升主版本；每版有 Changelog 并提交 Git。

## 设计采用的默认值

2026-09-29，用户进一步明确“mysql暂时不用，先用当前的简单数据库就行”，并要求将 SQLite 的测试、生产 DB 文件放入单独目录，提供可执行的测试造数 SQL。此决定覆盖本文件此前的首版生产 MySQL 设想；历史讨论仍由 Git 版本保留。v0.1.0 的正式发布以 SQLite 的真实初始化、隔离、备份/恢复和产品链路为数据库门禁，SQLite→MySQL 属于未来独立迁移版本。

2026-09-29，用户明确生产库预置 `admin / 123456` 供本人使用；测试库只供 Codex 执行应用程序回归。生产账号首次登录必须修改初始密码，初始化不得覆盖后续真实数据或已修改的凭据。此项覆盖此前“生产无内置口令”的设计；回归账号仍只在独立测试库生成。

2026-09-30，用户决定先以本机作为开发和测试环境。v0.1.0 App 默认连接本机服务 `http://127.0.0.1:49176`，登录界面允许配置服务地址。以后生产服务器确定后，在对应软件升级中提供新的 HTTPS 默认地址；用户已经手动配置的地址不能被升级覆盖。这里配置的是 TokenMeter 自身服务，不改变 Codex、Claude Code 等工具的 API 地址。当时本机缺完整 Xcode，随后改用Electron与Playwright；旧测试机授权不能转移为新客户端E2E通过。

2026-09-29，用户要求整体核对方案与落地后明确“修复这些问题”。按[一致性审查](reviews/2026-09-29-plan-consistency.md)修复流程循环、版本依赖、追踪校验和数据就绪边界。为实现“门禁先于 Tag”和逐版自动升级，增加候选提交入口，将最小更新器前移 0.1.0，0.10.0 完善体验；未改变强制真实 E2E 和 FAIL/BLOCKED 禁止发布规则。全部修改继续登记在未发布的当前基础版本。

2026-09-30，用户确认“以目前的测试条件为准，先走通链路”。首个内部版本只声明 macOS15 的 Apple Silicon/Intel 两架构，最低部署版本15.0；macOS14和其他主版本在后续独立验证，不再沿用初始macOS14+支持承诺。平台范围变化不减少六例真实原生回归和最终DMG门禁。

当前技术约定：Electron客户端、FastAPI 服务端；UTC 存储、Asia/Shanghai 团队默认时区；近 N 天含今天；当前macOS15 Intel实测范围。具体数据保留、同步、价格、功能拆解及测试矩阵见产品和架构文档，后续变更遵循 SOP-000/024 并更新版本档案。
