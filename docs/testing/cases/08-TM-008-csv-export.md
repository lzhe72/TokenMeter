## E2E-TM008-001 · 筛选一致的CSV导出

**验收：** `AC-TM008-001`，CSV 行/统计与授权可见筛选结果一致。

**前置/数据：** 数据集 `export_rows`；export_rows planned；两成员、两个模型、时间范围内外各有事件，独立清单明确每条ID/字段/权限。先具备TM-005/007统计和授权。

**步骤：**

1. 管理员从App选择固定时间、alice和一个模型，记录UI可见明细与筛选条件。
2. 通过真实保存对话框导出到本次隔离目录。
3. 用独立CSV解析器读取文件，核对列名、行ID集合与按输入手算的Token/费用。
4. 换为member alice重复相同允许筛选；修改筛选后另存第二文件并检查两文件互不覆盖。

**独立预期：** 每次CSV仅包含当次筛选且授权可见记录，行数/ID/汇总等于独立清单与界面；不混入旧筛选、其他成员或范围外记录。已知/未知费用语义一致。

**绑定/证据/状态：** `planned`；`automated_test=null`，未有原生函数绑定和执行证据。按 SOP-010/011 补齐后由 SOP-014 执行；缺项：缺export_rows生成器/SQL、导出页面/保存UI绑定、列合同与独立CSV oracle；当前无可执行导出命令。 预期证据包括当前release_id/候选SHA、输入与expected摘要、原始原生结果、逐步断言/必要截图、数据/故障恢复与清理记录；当前这些产品证据尚不存在。

## E2E-TM008-002 · CSV转义、未知值及权限

**验收：** `AC-TM008-002`，格式可解析，未知值保留，成员不能通过导出读取他人记录。

**前置/数据：** 数据集 `export_rows`；export_rows需含字段 `a,b`、`say "hi"`、带实际换行的项目名、未知费用与非ASCII模型名；两成员各有可区分哨兵事件。只在隔离数据中使用。

**步骤：**

1. 从App导出包含上述边界字段的授权记录。
2. 用标准CSV解析器读取并逐字段比较原始字符串，不能按行文本简单split。
3. 核对未知费用列和真正0费用列可区分，数值精度/编码符合列合同。
4. member尝试通过变更导出筛选/请求读取他人记录，检查UI错误、文件不存在或仅有本人授权内容。

**独立预期：** 逗号、双引号、嵌入换行均round-trip一致，Unicode不损坏；未知值不写成0；他人哨兵不出现在文件。若导出失败，不能留下看似完整的半文件。

**绑定/证据/状态：** `planned`；`automated_test=null`，未有原生函数绑定和执行证据。按 SOP-010/011 补齐后由 SOP-014 执行；缺项：缺边界fixture/SQL、CSV格式合同（编码/unknown表示/数值精度）、自动保存与权限绑定；须先定义合同后编写精确assert。 预期证据包括当前release_id/候选SHA、输入与expected摘要、原始原生结果、逐步断言/必要截图、数据/故障恢复与清理记录；当前这些产品证据尚不存在。
