## 输入、权限与失败行为

- 用户名 ASCII 3–64 位（字母、数字、下划线、短横线），一般账号导入及新密码 12–128 位；生产首建 `admin / 123456` 是本版明确约定的初始凭据，必须标记首次改密，改密前不能使用管理接口。登录和当前密码接收1–128位并按真实散列验证，短错误密码仍返回凭据错误；新密码不能等于旧密码，界面二次确认。生产首建不可覆盖已有账号或已修改的密码；测试账号仅隔离环境生成。
- 服务端 SQLite 文件分别放在 `database/test/test.db` 与 `database/production/production.db`。测试库只供 Codex 回归，生产库供用户使用；造数 SQL 由程序生成，可检查和执行，不能把测试账号导入生产库。
- 管理员不能停用自己或使最后一个活动管理员不可用；成员请求任何管理接口返回 403，不能由客户端提交角色升级。
- 初次改密前会话仅能访问本人身份、改密和退出。密码/状态变更原子撤销相关会话；启用不复活旧会话。
- 24 小时会话到期须重新登录。请求超时显示可重试错误；离线不将缓存身份当作认证成功。退出清理本机凭据；服务不可达时明确服务端撤销尚未确认，重试后再声称已撤销。
- v0.1.0 正式 App 首次默认服务地址为 `http://127.0.0.1:49176`，用户在登录界面可编辑。HTTP 仅允许本机回环地址（`127.0.0.1`、`localhost`、`::1`），其余主机必须使用 HTTPS；服务地址不能含账号、密码、路径、查询或片段。切换服务不得向新服务发送旧服务 token，手动配置跨重启保留；请求仍走服务端真实认证。测试构建可注入隔离地址和 Keychain 命名空间，正式包不得提供造数或认证旁路。密码不写日志/诊断/本地文件，token 仅存 Keychain，数据库保存 token 摘要。
