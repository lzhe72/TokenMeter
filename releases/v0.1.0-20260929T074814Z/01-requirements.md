## 输入、权限与失败行为

- 用户名 ASCII 3–64 位（字母、数字、下划线、短横线），一般账号导入及新密码 12–128 位；生产首建 `admin / 123456` 是本版明确约定的初始凭据，必须标记首次改密，改密前不能使用管理接口。登录和当前密码接收1–128位并按真实散列验证，短错误密码仍返回凭据错误；新密码不能等于旧密码，界面二次确认。生产首建不可覆盖已有账号或已修改的密码；测试账号仅隔离环境生成。
- 服务端 SQLite 文件分别放在 `database/test/test.db` 与 `database/production/production.db`。测试库只供 Codex 回归，生产库供用户使用；造数 SQL 由程序生成，可检查和执行，不能把测试账号导入生产库。
- 管理员不能停用自己或使最后一个活动管理员不可用；成员请求任何管理接口返回 403，不能由客户端提交角色升级。
- 初次改密前会话仅能访问本人身份、改密和退出。密码/状态变更原子撤销相关会话；启用不复活旧会话。
- 服务端签发随机、可撤销 token，最长固定 30 天有效期，不因调用 `/v1/me` 或普通请求而顺延；过期后须重新登录。登录页“在此设备上自动登录”仅在登录页可选、首次默认开启，之后在profile配置文件保留非敏感布尔选择；关闭时不读取持久凭据，成功登录接收新会话时删除当前 origin 旧文件，新 token 仅驻内存，App 重启显示登录页；保存失败则本次登录整体失败，不展示已验证身份。开启时 App 重启从受保护文件读取 token，但必须经真实 `/v1/me` 验证后才能显示已登录。离线、失效或认证请求失败不能把缓存身份当作成功；请求超时显示可重试错误。退出、改密、管理员重置或停用时服务器撤销相关 token；客户端清理自己持有的持久凭据，服务不可达时明确撤销尚未确认，不声称服务器已撤销。
- v0.1.0 正式 App 首次默认更新源为 `http://127.0.0.1:49177/version.json`，由运行 App 的同一台 Mac 提供，API 默认端口仍是 49176。用户可在配置管理页改更新源；显式覆盖跨重启和升级保留，恢复默认删除覆盖而随新版内置默认更新，固定 EdDSA 公钥不随 URL 改变。更新 URL 允许版本清单路径，但拒绝 userinfo、query、fragment、空主机及非法端口；HTTP 仅允许精确回环主机 `127.0.0.1`、`localhost`、`::1`，非回环仅 HTTPS。选中下载 URL 与重定向不得越过该边界；本轮合成配置 URL 只核对保存/重启/恢复，不请求其服务器。配置页保存前同时验证 API 与更新 URL，取消不保存；恢复默认立即删除两项显式覆盖，已登录或退出待确认时锁定 API 编辑与总恢复默认，更新进行中锁定更新源编辑。
- v0.1.0 正式 App 首次默认服务地址为 `http://127.0.0.1:49176`，用户在登录界面可编辑。HTTP 仅允许本机回环地址（`127.0.0.1`、`localhost`、`::1`），其余主机必须使用 HTTPS；服务地址不能含账号、密码、路径、查询或片段。切换服务不得向新服务发送旧服务 token，手动配置跨重启保留；请求仍走服务端真实认证。生产持久凭据仅位于 `~/Library/Application Support/TokenMeter/credentials`，目录0700、文件0600、当前 uid、拒绝符号链接，按规范化 API origin（scheme/host小写、去默认80/443端口及尾斜线）隔离并原子写入；不保存密码，服务器数据库只保存 token 摘要。“在此设备上”指本机文件保存范围，不作硬件绑定；同uid进程可读取，复制的token可能在别处使用。正式包支持通用独立工作目录，测试通过`--user-data-dir`和受保护的App旁portable配置隔离，升级后仍回同一profile；详见[设计](../../docs/architecture/01-electron-local.md)。既有Keychain和用户旧App数据不被测试读取或迁移；不提供造数或认证旁路，凭据不进入日志/构建物。
