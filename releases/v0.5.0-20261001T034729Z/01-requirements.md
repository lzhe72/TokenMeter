# TM-005 用量统计需求草案

**release_id：** `v0.5.0-20261001T034729Z`
**状态：** draft / baseline_pending；未执行产品测试，未发布。

## 用户与可见结果

`REQ-TM005` 面向已授权本机日志目录并完成采集的用户。界面提供今天、昨天、近 7/15/30 天及自定义日期筛选，显示 Token 指标、逐日趋势、调用明细和模型维度。`AC-TM005-001` 要求各视图与独立预期一致；`AC-TM005-002` 要求当地自然日边界正确，明确区分无覆盖、已覆盖零调用与字段未知。

## 已确认规则

- 事件时间存 UTC；显示和筛选采用团队时区，默认 `Asia/Shanghai`。日期范围为当地日左闭右开；近 N 天包含今天。
- `total_tokens = input_tokens + output_tokens`；缓存读取和缓存写入属于 input，推理输出属于 output，不额外相加。缺失子项保持未知，不以 0 代替；模型字段未知但用量可信时仍计入“未知模型”组。
- 重复源事件只入账一次。模型不可识别时保留来源标识，不能把未识别模型当作价格为零。本版不计算费用，价格属于 TM-006。
- 客户端只读用户授权的源日志；统计只展示可信用量及覆盖/诊断状态。提示词、回复、代码、密钥与完整本机路径不进入统计库或服务端。

## 确定的范围与依赖

用户已明确另设 TM-004 Claude Code 采集会话；TM-005 保持既定 Codex + Claude Code 双来源，不缩减 `REQ-TM005`、`AC-TM005-001/002` 或 E2E 集合。[产品约定](../../docs/product/README.md)和[功能矩阵](../../tests/feature_matrix.json)中的 TM-003、TM-004 均为正式依赖，目前仍为 planned。两项需提供可追踪的稳定源码提交、原生日志版本与去重/覆盖合同，并通过其各自产品 E2E 后，TM-005 才能完成真实链路实现与回归。

TM-001 已形成干净 Electron 候选 `3467dc1`，但尚无最终 DMG 产品门禁；本分支仍未合入其源码。团队同步/跨设备统计属于 TM-007；TM-005 在同步前展示当前登录身份在本机授权来源中的用量。规范化 fixture 的 `test-alice`/`test-bob` 字段只作语义样例，TM-005 的双来源原生 E2E 把全部本机事件绑定到单一合成登录账号以核对日期、模型和总量，不把跨账号团队统计提前声称交付。
