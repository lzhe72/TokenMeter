## 用户、问题与版本边界

本轮仅负责 `REQ-TM002` / `TM-002` 首次授权。团队成员在完成 `TM-001` 的真实登录后，为本机既有 Codex 或 Claude Code 日志明确选择来源目录，并决定是否允许持续采集、是否愿意在后续同步功能中上传用量。首次选择可预览候选文件；取消、拒绝或来源失效时 App 保持可用。既有验收定义见[产品约定](../../docs/product/README.md)和[规划用例](../../docs/testing/cases/02-TM-002-permissions.md)。`TM-001` 当前尚未获得完整产品 E2E PASS，不能将其视作已发布基座。

本版只建立授权、候选文件预览及可供后续来源适配器调用的访问边界；`TM-003`/`TM-004` 负责具体日志解析和去重，`TM-007` 才负责实际同步。确认“愿意同步”本身不能触发上传。候选预览只表示所选根内的普通 `.jsonl` 文件符合语法候选规则，不承诺内容能被后续解析器识别。不得扫描真实用户目录来准备测试数据，不得将提示词、回复、代码、密钥或完整本机路径写入用量库、服务、诊断报告、测试表或 Git。

## 已确定的行为方向

| 验收 | 输入与可观察结果 |
| --- | --- |
| `AC-TM002-001` | 已登录成员通过 macOS 原生目录选择器选择一个工具来源目录。选择器取消不改变已确认状态。预览只列出选中根内符合候选规则的文件名称/必要元数据，不解析或持续监听日志；未经明确确认，不能建立持续读取任务。确认后至少可触发受控的候选元数据刷新，以独立验证读取范围，而不提前实现 TM-003 的正文解析。用户分别确认采集和后续同步意愿，重启并经真实账号验证后只恢复该账号已确认的选择与意愿。B 未经选择时不得出现在预览或读取记录中；确认换根至 B 后只允许读取 B。 |
| `AC-TM002-002` | 用户撤销选择、已选目录不可访问、被替换或失效时，停止该来源的受控刷新及后续持续读取并显示需重新选择；App 仍可登录、配置和查看状态。通过原生选择器重新选择可访问目录并确认后恢复刷新和来源状态；取消重新选择保持停止状态，不复活旧授权。 |

来源状态按服务 origin 与真实账号 ID 隔离；退出或切换账号不能向新账号显示或读取旧账号来源。目录遍历必须拒绝符号链接逸出和选中根以外的路径。预览可读取文件系统元数据，但不读取日志正文；持续采集需经明确确认。原始日志只读，授权流程不得改写它们。同步意愿默认关闭，取消同步意愿不删除既有本机授权；它对未来 `TM-007` 的上传行为是否生效，由该版按其需求验证。

Codex 与 Claude Code 两个工具来源均允许经原生面板选择；来源在本版只按用户选择的根、工具类型和身份隔离。候选枚举从所选根递归，只接纳非符号链接的普通 `.jsonl` 文件，选中根为深度 0、最多深入 8 层目录，最多展示 1000 个候选、检查 5000 个目录项、运行 2 秒；达到任一上限必须标明预览不完整，不能当作“无日志”或“已覆盖全部”。相对候选名必须以选中根为基准，不暴露其绝对路径。来源格式和统计准确性仍由 `TM-003/004` 独立验证。

## 已确认的授权模型与本地存储边界

用户已明确本版使用 **macOS 原生目录选择器 + App 持久保存已选来源 + 主进程强制限制读取范围**。选择过程必须真实调用系统面板，renderer 不能自行传入路径；后续每次预览或刷新必须按所选根、已验证 origin/account.id 和当前采集状态检查。用户在 App 内撤销或目录不可访问、被替换时停止读取，重新选择须再次经过真实面板与明确确认。macOS 沙盒级 security-scoped grant、TCC 撤销与系统对非沙盒 App 的逐目录隔离**不在本版验收声明内**。现有非 MAS Electron 构建与 [Electron 目录选择器文档](https://www.electronjs.org/docs/latest/api/dialog)相符；不能用 native dialog 的存在声称已验证 App Sandbox 授权。旧文案“真实系统授权/撤销”已同步改成该可执行边界。

用户已明确要求 App 持久保存所选目录，因此允许仅在当前用户私有的 `sources/` 记录中保存恢复该目录所必需的 locator。主进程以 Electron `safeStorage.encryptStringAsync` 加密规范化目录路径，密文写入 0700 目录内的 0600 文件；macOS 密钥由 Keychain 保护。密钥暂不可用、解密失败、记录损坏或根身份变化时停止读取并提示重新选择，绝不回退明文。App 内撤销删除该记录。该密文是本机恢复信息，**不是** macOS 沙盒授权；每次访问仍核对身份、POSIX 可读性及根身份。完整路径及 locator 不进入用量库、同步数据、服务端、renderer、日志、测试报告或 Git。此有限的私有存储例外已按 SOP-000 写入 SOP-002/004/006；需求及用例经 SOP-008 核对后方可进入实现。

同一服务 origin、已验证账号与工具类型只保留一个已确认来源根。再次打开面板后取消，或在旧来源和系统密钥均健康时新记录的原子写入失败，原已确认根与意愿维持原样；系统密钥整体不可用或旧密文解密失败则停读需重新选择。成功确认新根时原子替换记录并立即停止旧根的扫描能力。已确认来源允许用户分别改变采集和未来同步意愿；关闭采集立即停止受控读取，再次开启须用户明确操作。目录失效后用户仍可撤销并删除旧密文。测试 profile 不能仅凭 `--user-data-dir` 声称 Keychain 隔离；依赖系统密钥的产品用例须先按 SOP-009/010 对同一最终 DMG 取得实际隔离身份、签名边界和本例精确所有权证据，否则保持 BLOCKED。
