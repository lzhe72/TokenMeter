同一最终候选 DMG 安装到本次运行独占位置，以固定 Playwright Electron 程序驱动真实 UI、主进程 IPC、隔离 FastAPI/SQLite，并由系统 UI 驱动**真实** macOS 目录面板。TM-002 两组场景的所有细化产品 TC 与 TM-001 全部已交付细化 TC/六组补充场景在最终包上逐条记录；每例使用独占测试 profile、动态端口、合成账号和来源目录 A/B，证据不能借用开发包或旧候选。测试 profile 须在异步 `safeStorage` 首次调用前取得目标 Keychain service/account、签名访问边界及测试 item 此前不存在的证据，证明与正式 App 项分离；正式密钥项不得被查询、修改或删除。缺证据时相关 E2E 为 BLOCKED。原始日志、源码/private 路径、默认生产凭据、既有用户 App、生产库和用户服务均不作为测试对象。

## 部署顺序、停止与恢复

TM-002 预期不改服务端 API/SQLite schema；先在隔离环境验证与已发布服务协议兼容。实际推广前按 [数据库说明](../../database/README.md)和 [SOP-020](../../sop/SOP-020-deployment.md)备份并验证真实生产库可恢复，确认所连服务健康，再推广已验 DMG；不得因本版无预期迁移而跳过备份/恢复核对。不能更换用户现有 App、覆盖其安装位置或终止用户服务作为回归准备。

本机门禁 PASS 后依 [SOP-020](../../sop/SOP-020-deployment.md)在 `dmg/v0.2.0-20261001T034118Z/release-archive/` 独占归档同一原包、原始证据和通行证，读回 SHA；仅此时把正式原名 DMG 放入该版本目录，形成可供下一版升级的本机稳定包。按开发总控流程交付本地0.2里程碑 SHA/tree、原始证据和结论。全部目标源码完成后，总控可按远端保护登记master并读回本版来源里程碑；正式Tag只在用户启动发布且最终候选门禁/归档PASS后登记。远端源码阶段与发行原件分别记录。任何包或源码内容变化须新候选重新测试。

签名/系统面板自动化权限、上一稳定包、真实更新、TM-001 回归或任一 TM-002 TC 缺失时，停止发包及签发通行证，保留 FAIL/BLOCKED 原始结果。修复按 [SOP-015](../../sop/SOP-015-bugfix.md)稳定复现、改代码/用例/数据并全量重跑；部署失败按 [SOP-021](../../sop/SOP-021-rollback.md)停止推广、恢复备份与旧包，核对实际服务/数据状态后再决定下一候选。
